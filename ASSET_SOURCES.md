## Motion references

The implementation adapts interaction patterns from the reference sites supplied with the brief: scrubbed camera zoom from [CodePen’s GSAP ScrollTrigger examples](https://codepen.io/GreenSock/pen/YzbPYMx), scroll-linked mask reveals from [Motion’s image reveal example](https://motion.dev/examples/react-scroll-image-reveal), and SVG path animation principles from [Anime.js](https://animejs.com/documentation/svg/). The page keeps its own Ableton editorial visual language and uses GSAP plus native CSS rather than adding those libraries as dependencies.
